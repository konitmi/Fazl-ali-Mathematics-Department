MATHS DEPARTMENT WEBSITE
=========================
Files:
- index.html
- style.css
- script.js

IMAGE PLACEHOLDERS
------------------
The site intentionally uses dark boxes instead of fake images.
You can add:
- banner.png  -> main event/banner image
- about.png   -> department/about image

PYQ
---
The PYQ buttons are placeholders. Add your PDF links/files in index.html when you have them.

CUSTOMISING
-----------
Edit script.js to change formula lists, quiz questions, mental-math questions and department strength.
No backend or external libraries are required. It works on GitHub Pages.
